## 🚀 Run Locally

### Prerequisites

- A modern web browser
- Git installed on your computer

### Installation

Clone the repository:

```bash
git clone https://github.com/Narasimha289/portfolio.git
```

Navigate to the project directory:

```bash
cd portfolio
```

Open `index.html` in your browser to view the portfolio.

If you use the project's server-side functionality, follow the configuration and startup instructions in the `server` directory.
